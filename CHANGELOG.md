# Just Enough Items: Terraria Edition · 更新日志 / Changelog

## JEI 0.1.106

### 简体中文

- 输入 # 可浏览物品分类和配方组。输入 #acc 或 #配饰 可缩小范围，滚轮浏览，点击或按 Tab 补全。候选名称跟随游戏语言，模组配方组也会显示作者提供的译名。
- @ 模组列表会自动显示模组图标。按 Tab 补全时使用模组内部名称，切换语言后也能沿用同一条搜索。
- 拼音搜索支持更多多音字读音，例如输入 chongzhu 可以找到“重铸”。
- 修复同一物品同时出现在工作台、配方页或书签中时，图标可能向左偏出格子的问题，也修复了桶类物品的图标错位。
- 新增客户端设置「在原生背包中禁用书签快捷键」，默认开启。需要在原生背包里按 A 添加或取消书签时，可关闭此项。JEI 界面内仍可照常使用书签快捷键。

### English (machine translation)

- Type # to browse item categories and recipe groups. Type #acc to narrow the list, scroll to browse, then click or press Tab to complete. Names follow the game language, including translations supplied by other mods.
- The @ list now shows each mod’s icon. Tab completes the mod’s internal name so the same search works across languages.
- Pinyin search now recognizes more readings of Chinese characters. For example, chongzhu now finds “重铸”.
- Fixed item icons shifting left when the same item appeared at a crafting station, on a recipe page, or in bookmarks. Bucket icons also stay inside their slots.
- A new client setting disables the bookmark hotkey in the vanilla inventory by default. Turn it off to add or remove bookmarks there with A. The hotkey still works inside JEI.

## JEI 0.1.97

### 简体中文

- 修复了部分物品图标偏移、超出格子的问题。图标首次显示和再次显示时都会在格内居中。
- 修复了反复收藏或取消收藏物品、配方时可能导致闪退的几种情况，包括配方刷新后当前页变空的情况。

### English (machine translation)

- Item icons now stay centered within their slots, both the first time they appear and when shown again.
- Fixed several cases where repeatedly adding or removing favorite items or recipes could cause a crash, including when refreshing recipes left the current page empty.
